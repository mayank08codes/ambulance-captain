# External Reference Notes

## Savife reference

Source: https://savife.vercel.app/

Observed interaction patterns: the landing experience centers on the user’s location, a quick symptom/triage selection area, a prominent SOS emergency ambulance action, and emergency helpline shortcuts. The visual direction is emergency-focused and location-first. These patterns informed the Ambulance Captain workflow: location visibility, rapid request review, safety-oriented status feedback, and clear emergency actions.

The current Ambulance Captain product remains driver-facing. Customer booking, driver assignment, OTP verification, live GPS routing, hospital recommendation, arrival detection, and payment handoff are being implemented as connected workflow states rather than isolated static pages.
